Continuidad por preimagen de abiertos

La función es continua si para cada V ∈ τY, se cumple f⁻¹(V) ∈ τX.

Continuidad usando una base

En este caso podemos usar la base B = {{1}, {1,2}, Y}. Basta verificar las preimágenes de esos abiertos básicos.

Conclusión sobre homeomorfismo

Acá usamos el criterio: f es homeomorfismo si es biyectiva, continua y abierta. Para una función biyectiva, que sea abierta equivale a que f⁻¹ sea continua.
